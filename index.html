ℹ️ Acerca de LOG Calendar

Información técnica, privacidad y arquitectura de la aplicación.

LOG of Growth Versión 4.0.0 ✓ Al día ✓ Modo app activo

Aplicación web Local-First diseñada para optimizar el estudio, el seguimiento de hábitos y el bienestar personal con privacidad total.

  • 🔒 Privacidad Absoluta: Cero cookies de seguimiento, cero llamadas a servidores externos y ejecución 100% en local.
  • 💾 Arquitectura Local-First: Compatible con File System Access API para almacenamiento nativo en archivos físicos JSON.
  • ⚡ Rendimiento Extremo: Cero dependencias npm, cero bundlers y código Vanilla JavaScript nativo.

Actualización del Sistema

🚀 Nueva versión disponible

Hay una nueva versión de LOG Calendar lista para descargar.

¿Cómo actualizar tu copia local?

  1. 1. Descarga el paquete .zip de la última versión en GitHub.
  2. 2. Descomprime los archivos y reemplaza los archivos del programa (.html, .js, .css) en tu carpeta de LOG Calendar.
🛡️ ¡Tus datos están 100% a salvo!

Todas tus horas registradas, asignaturas, hábitos y notas residen en el almacenamiento de tu navegador (localStorage) o en tu carpeta conectada en disco. Reemplazar los archivos del programa no altera ni borra tus datos.
